# Target Strike

Target Strike is a Unity-based first-person shooter game for Windows PC. The project features normal and zombie gameplay modes, enemy AI navigation, raycast shooting, pickups, score tracking, timer-based objectives, and multi-scene game flow.

The project focuses on core FPS systems including player movement, combat, enemy state behaviour, health management, and interface feedback. Open the project with Unity 2020.3.24f1 and use Build Settings to create a playable build.

## Gameplay

- Eliminate enemies before the timer ends to complete the level.
- Enemies patrol until they detect the player, then chase and attack.
- Health, ammo, grenades, and score are tracked through the HUD.
- Ammo pickups and medikit pickups are placed in the level.
- Two guns and grenades are available during play.

## Features

- First-person player controller with movement, jumping, running, aiming, and shooting.
- Enemy AI with patrol, chase, attack, and death behaviours.
- HUD elements for health, ammo, grenades, timer, score, and crosshair.
- Multiple enemy types including zombies, soldiers, and flying robots.
- Particle effects and audio feedback for combat and environment responses.
- Scene flow for menu, gameplay, win, and loss states.

## Controls

| Action          | Desktop PC              |
| --------------- | ----------------------- |
| Move Forward    | W                       |
| Move Left       | A                       |
| Move Backward   | S                       |
| Move Right      | D                       |
| Jump            | Space                   |
| Run             | Left Shift (hold)       |
| Shoot           | Mouse Left Button       |
| Aim             | Mouse Right Button      |
| Previous Weapon | Q or Mouse Wheel Up     |
| Next Weapon     | Q or Mouse Wheel Down   |
| Reload          | R (when near ammo box)  |
| Health Recharge | Caps Lock (near medikit)|
| Throw Grenade   | G                       |
